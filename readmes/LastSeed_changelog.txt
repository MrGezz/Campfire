===========================================
Last Seed 0.3.0 Change Log
===========================================

- The needs systems are complete. Thirst, Fatigue, progressive diseases, alcohol and skooma,
  food spoilage and preservation, water sources and waterskins, follower needs and the
  Provisioning skill tree all run, and the Mod Configuration Menu has its full set of pages.
  These systems come from Aytrus's Last Seed 5.3 (Nexus Mods 56393), which continued Chesko's
  original with his permission, and are used here with credit.
- (Special Edition) SKSE is detected on Special Edition. The check only ran on Legendary
  Edition, so on SE the settings-profile load on startup and the meter presets never fired.
- (Special Edition) Plugin detection no longer uses Game.GetModByName(), which returns 255 for
  light (ESL-flagged) plugins and reported them as missing.
- (Special Edition) SkyUI is looked up as SkyUI_SE.esp as well as SkyUI.esp everywhere,
  including the Mod Configuration Menu's Profiles page, which read a property off None.
- Fixed the ice wraith teeth message: its property was declared without the Property keyword,
  so the plugin's value never reached the script.
- Fixed the Add Portions to Provisions setting writing over the Auto-Eat setting in settings
  profiles, and showing its own label instead of its help text.
- Translations: the meter height help text was filed under the meter width key, and five meter
  settings borrowed Frostfall's strings. Both fixed in all nine languages.
- Campfire's follower registration now skips horses and reanimated followers and stops follower
  food spoilage on unregistration, guarded so Campfire still works without Last Seed.
- Requires powerofthree's Papyrus Extender, built for runtime 1.7.104.
- Every script is compiled from the sources that ship with it. Nineteen were not, so the ice
  wraith teeth fix above and the stumbling fix below had never reached the game; the other
  seventeen were verified to come out with exactly the same shape they had before.
- Fixed the drunk stumbling effect, whose source declared the tripping chance property twice
  and so could not be compiled at all.

===========================================
Last Seed 0.2 Change Log
===========================================

- Eating and drinking animations. Food and drink now play the game's own standing or seated eating and drinking idles, the way Frostfall plays its hand-warming idle: third person while it plays, back to first person afterwards, and never in combat, with a weapon out, sneaking, riding or swimming. Tracked followers (Campfire, up to three) eat and drink when you do. Both are on by default and can be turned off on the new Effects & Notifications page of the Mod Configuration Menu, which also exposes the existing sound, full screen effect, force feedback and condition message settings.
- Fixed the Gameplay page of the Mod Configuration Menu: every click toggled Focus, because the option ids were never compared.
- First release that can be packaged from the Skyrim Survival repository: Last Seed now has
  an archive manifest, a release builder, readmes, and an English MCM translation file.
  Until now the Mod Configuration Menu showed raw $LastSeed... keys.
- (Special Edition) Last Seed now detects and uses SKSE64, and requires the build of SKSE
  matching your runtime: SKSE 1.7.3+ on Legendary Edition, SKSE64 2.0.20+ on Special
  Edition, SKSEVR 2.0.12+ on VR. Previously it skipped SKSE detection entirely on Special
  Edition and always ran in Fallback Mode.
- (Special Edition) Fixed light (ESL-flagged) plugins being reported as not loaded during
  compatibility checks.
- (Special Edition) SkyUI_SE.esp is now looked up alongside SkyUI.esp in the compatibility,
  startup and MCM scripts.
- (Special Edition) The perished food mesh is converted to the Special Edition format when
  the release is built.
- Fixed a crash in the Mod Configuration Menu's Save/Load page if SkyUI could not be
  resolved.
- The provisioning skill tree is no longer registered with Campfire. It was a stub - a
  controller with no perk nodes, attaching a script name Campfire stopped shipping in
  2016 - and opening it from a campfire failed. It returns when the tree is built.
